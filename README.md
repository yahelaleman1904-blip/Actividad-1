# Actividad 1 - Programación Web

Repositorio con los ejercicios prácticos del Tema 2 de la materia Programación Web.

Elaborado por Carlos Yahel Aleman Cruz

## Contenido

Ejercicio 1: Hola Mundo: Estructura fundamental de un documento HTML con la etiqueta básica para mostrar texto simple en el navegador.

Ejercicio 2: Párrafos y Formato Básico: Aplicación de etiquetas de texto para estructurar párrafos y dar formato visual (como negritas o cursivas).

Ejercicio 3: Enlaces Simples: Implementación de la etiqueta <a> para crear hipervínculos que conectan con otras páginas o recursos externos.

Ejercicio 4: Imágenes Básicas: Inserción de imágenes con la etiqueta <img>, manejando rutas de carpetas locales y atributos de texto alternativo.

Ejercicio 5: Combinando Texto y Enlaces: Integración de vínculos navegables directamente dentro de bloques de texto para crear hipertextos fluidos.

Ejercicio 6: Secciones Semánticas Básicas: Uso de etiquetas estructurales de HTML5 para dividir y organizar el contenido de la página de forma lógica.

Ejercicio 7: Listas Anidadas (Tacos al Pastor): Creación de listas ordenadas y desordenadas dentro de otras listas para jerarquizar recetas o pasos.

Ejercicio 8: Horario de Clases: Construcción de una tabla HTML clásica (table, tr, td) para organizar datos en filas y columnas.

Ejercicio 9: Formulario de Contacto: Diseño de una interfaz de captura de datos utilizando etiquetas form, campos de entrada input, y botones.

Ejercicio 10: Calculadora JS (Celsius a Fahrenheit): Primera integración de JavaScript para leer un valor de un input numérico, aplicar una fórmula matemática de conversión y mostrar el resultado.

Ejercicio 11: Kilómetros a Millas: Script de conversión de unidades que valida que los campos no estén vacíos y comprueba que el valor sea numérico antes de imprimir la respuesta en un campo de solo lectura (readonly).  

Ejercicio 12: Pesos a Dólares: Calculadora de divisas que bloquea la entrada de números negativos e implementa una multiplicación con una tasa de cambio fija (0.055).  

Ejercicio 13: Verificador de Edad para Votar: Aplicación de lógica condicional (if/else) para evaluar si el número ingresado cumple con la mayoría de edad legal (18 años) sin necesidad de recargar la página.  

Ejercicio 14: Operaciones con Arreglos: Procesamiento de una cadena de números usando split() para transformarla en un arreglo (Array), sobre el cual se aplican métodos como reduce() para el promedio, y Math.max()/Math.min() para los valores extremos.  

Ejercicio 15: Objetos en JavaScript (Estudiantes): Sistema para agrupar variables vinculadas (nombre y calificación) dentro de Objetos, guardándolos en un arreglo para iterarlos con map() y extraer al alumno con el mejor y peor desempeño.  

Ejercicio 16: Calculadora con Funciones Flecha: Refactorización de operaciones aritméticas utilizando sintaxis moderna de ES6 (=>) e integración de la librería externa SweetAlert2 para disparar alertas visuales al detectar errores.  

Ejercicio 17: Gestión de Tareas (Local Storage): Aplicación To-Do que encapsula sus variables mediante closures para mantener la seguridad del código, persistiendo los datos en formato JSON dentro de la memoria del navegador (localStorage) para que no se borren al actualizar.  

## Tecnologías

HTML5, CSS3, JavaScript.
