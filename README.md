# Actividad 1 - Programación Web

Repositorio con los ejercicios prácticos del Tema 2 de la materia Programación Web.

Elaborado por Carlos Yahel Aleman Cruz

## Contenido

* Ejercicio 1: Cree una pagina HTML con el clasico Hola Mundo!.
* Ejercicio 2: Utilice formatos basicos.
* Ejercicio 3: Cree enlaces, utilizando estos tres tipos: target="_blank", target="_self".
* Ejercicio 4: Utilice el img para insertar imagenes basicas: alt, width.
* Ejercicio 5: Aqui ya combinamos el texto con los enlaces, dentro de párrafos.
* Ejercicio 6: Utilice secciones semánticas.
* Ejercicio 7: Listas anidadas para recetas.
* Ejercicio 8: Horario estructurado con tablas.
* Ejercicio 9: Formulario de contacto con estilos CSS.
* Ejercicio 10: Calculadora funcional con JavaScript.

## Tecnologías

HTML5, CSS3, JavaScript.
